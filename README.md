# Uni House Sim

A small browser game about surviving a 12-week term in a shared student house.
Balance money, grades, sanity, a tidy house and your housemates' patience.

## Play
Open `index.html` in a browser, or enable GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root) to host it.

## How it works
- Each week you get 3 actions, then pay rent and bills.
- A random house event forces a choice.
- Run any stat to zero (or go too far overdrawn) and the term ends early.
- Finish week 12 to get your degree classification.

## Customise
Edit `ACTIONS`, `EVENTS` and the constants at the top of `game.js`.
No build step or dependencies.
