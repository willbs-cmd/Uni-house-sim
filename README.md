# Uni House Sim — fixed

This version fixes the broken JavaScript and turns the project into a complete 12-week browser/Streamlit game.

## Features
- 12-week term loop
- 3 actions per week
- Money, grades, sanity, house condition and housemate relations
- End-of-week rent/bills
- Random choice events
- Adult-only humour, dating, drinking and messy student-life scenarios
- Game-over conditions and a final degree result
- Responsive UI that works on desktop and smaller screens

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

Or open `index.html` directly for the browser version.
